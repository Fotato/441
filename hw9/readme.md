# AI

In some instances I couldn't figure out why something wasn't moving only to find out via AI that I needed to change the default behavior for something like position. 

Also, in JQuery there was a ton of nesting functionality and it got to be really cumbersome. I used AI to give me ideas on how I could make it a little less messy.
